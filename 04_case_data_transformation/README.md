# Day 4 – CASE WHEN & Data Transformation

## 🎯 Objective

Practice SQL data transformation and conditional logic using
CASE WHEN, string functions, and NULL handling.

## 🛠️ SQL Concepts Covered

- CASE WHEN
- Conditional classification
- GROUP BY
- Subqueries
- Aggregate functions
- LENGTH()
- NULL handling
- IS NULL
- COALESCE()
- Data transformation

## 📊 Business Problems Solved

1. Classified employees based on salary.
2. Identified high-salary employees.
3. Counted employees by salary category.
4. Calculated total salary expense by category.
5. Created salary-based HR actions.
6. Calculated average salary by category.
7. Analyzed employee name length.
8. Classified names based on length.
9. Identified missing salary data.
10. Replaced missing salary values with 0.

## 💡 Key Learning

CASE WHEN can transform raw data into meaningful
business categories.

A common SQL analysis pattern is:

Raw Data
↓
Transformation
↓
Aggregation
↓
Business Insight
